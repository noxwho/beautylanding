# BeautyLanding

Демонстрационный сайт небольшой студии красоты Beauty Atelier. Название, описание услуг, преимущества, цены и длительность процедур — примеры, а не сведения о действующей студии. Отзывы и реальные контакты отсутствуют. Запись не подключена.

## Запуск

Откройте index.html в браузере двойным щелчком. Сборка, установка пакетов и сервер не требуются. Для разработки также подходит локальный статический сервер редактора с корнем в BeautyLanding.

## Состав

- index.html — все шесть разделов и метаданные.
- styles.css — адаптивный дизайн и авторские абстрактные композиции на CSS.
- menu.js — мобильная навигация: раскрытие, Escape, закрытие по клику снаружи, уходу фокуса и выбору раздела.
- icon.svg — собственная иконка вкладки.

Нет внешних библиотек, шрифтов, трекеров, платных сервисов и чужих фотографий. Портфолио явно обозначено как иллюстрации. При отключении JavaScript ссылки меню остаются доступны. Поддерживаются видимый фокус, ссылка пропуска навигации и prefers-reduced-motion.

## Публикация

Загрузите index.html, styles.css, menu.js и icon.svg в одну корневую папку любого статического хостинга. Сборка не нужна; входной файл — index.html. Включите HTTPS. README загружать необязательно. Автоматическая публикация не выполнялась.

## Перед публикацией

1. Проверьте ширины 320, 393, 768, 800, 801, 1024 и 1440 px, альбомную ориентацию и масштаб 200–400%. Не должно быть горизонтальной прокрутки и наложения текста.
2. Проверьте каждый якорь, закрытие меню по выбору, клику снаружи и Escape, переход через границу мобильной ширины. Проверьте Tab, Enter/Space, видимый фокус и работу скринридера.
3. Отключите JavaScript и убедитесь, что меню осталось доступно. Включите системное уменьшение движения.
4. Проверьте Chrome, Safari и Firefox, реальные телефоны, Lighthouse, контраст, скорость и отсутствие ошибок в консоли. Эти браузерные проверки при создании проекта не выполнялись.
5. Если сайт становится реальным, замените демонстрационные сведения на согласованные данные студии, добавьте действующий адрес, часы работы и способ записи. Уберите обозначения демо только после замены всех примеров.
6. Используйте для будущего портфолио только собственные или разрешённые фотографии, с согласием изображённых людей. Сейчас фотографий нет.
7. Обновите title и description. Когда будет известен адрес публикации, добавьте canonical и метаданные для социальных сетей с настоящим URL.
8. На опубликованном HTTPS-адресе проверьте загрузку всех файлов, мобильное меню, кеширование и сжатие. Если появится форма, отдельно реализуйте отправку, обработку ошибок и необходимые условия обработки персональных данных.
